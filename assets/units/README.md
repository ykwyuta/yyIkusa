# ユニットの方向・歩行差分

内蔵image_genで生成した透過2D原画。全8兵種に5方向×5コマ、計200セルを用意する。`generation.json` に生成プロンプトと元ファイル名を保存。

原画 `movement/<id>.png` は5列×5行。行順は **東・南東・南・北東・北**。各行は **待機・歩行1・歩行2・歩行3・歩行4**。西・南西・北西は対応する東向き画像の左右反転で表示し、画面上の8方向をそろえる。北方向は背面、南方向は正面。

`src/unit_animation.rs` が方向とコマを選ぶ。移動中は実際の変位から求めた向きを優先し、進んだ距離で歩行周期を進める。攻撃目標の方向に引っ張られず、停止・障害物への引っ掛かり・一時停止では足踏みしない。待機・デコイ・撃破済みは待機コマを使う。停止中に交戦している部隊は照準方向へ向く。

大砲は砲兵2人が歩いて押す画像、騎兵と象兵は四肢の異なる歩行画像を持つ。武器は原画に含まれ、旧来の武器図形を重ねない。

```powershell
./tools/pack_unit_motion.ps1
cargo test --locked --lib
```

梱包は透過を保ったセル切り出し・固定倍率縮小・RGBA変換のみ。フレームごとに個別の拡大や再配置をしない。`walk_cells.rgba` は128×128×200セル、`assets/sprites/oblique_atlas.rle` は既存の本陣などと結合した16列×14行のアトラス。

[8方向のアニメーション確認](motion-preview.html)／[歩行コマ一覧](movement-preview.jpg)／[8方向の表示確認](direction-preview.jpg)。確認ページは画像の向きと4コマを表示する資料で、ゲーム本体の歩行速度は経過秒数ではなく実移動距離に連動する。
