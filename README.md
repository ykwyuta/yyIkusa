# yyIkusa — 英雄の戦場

YYww2の予算制・準備配置・リアルタイム戦闘・将軍への指揮委任を引き継いだ、時代を超えた英雄たちの合戦ゲーム。Rust製で、Windows版とブラウザ版（WebAssembly）を同じシミュレーションで動かす。

## 遊び方

1. 戦場、予算（3000／6000／11000）、敵の強さを選ぶ。
2. 8兵種を自由に購入し、自陣に配置する。国籍による制限はない。
3. 必要なら将軍を選び、配置した部隊をクリック／範囲選択して委任する。
4. 開戦後は直轄部隊を操作する。委任部隊は将軍の戦略に従って自動行動する。
5. 敵本陣を占領するか、敵の戦闘部隊を全滅させれば勝利。15分で決着しなければ残存戦力で判定する。

| 兵種 | 調達費 | 役割 |
| --- | ---: | --- |
| 象兵 | 720 | 高耐久の近接部隊。遅いが前線を支える |
| 歩兵 | 100 | 安価な槍の近接部隊 |
| 鉄砲隊 | 240 | 高い突破力の射撃。攻撃間隔が長い |
| 大砲 | 820 | 最長射程・大打撃。移動と攻撃が遅い |
| 騎馬槍隊 | 350 | 高速の近接攻撃。側面や背後を突く |
| 騎馬鉄砲隊 | 430 | 機動力のある銃撃部隊 |
| 騎馬弓隊 | 300 | 最速の騎射。偵察と遊撃向け |
| 弓隊 | 150 | 安価な遠距離支援 |

数値は史実の兵器性能の再現ではなくゲーム用の抽象値。正面・側面・背面の防御差、地形の移動補正、視界と遮蔽物を継承する。

## 将軍：女性10枠・男性10枠

全将軍が固有スキルを持ちます。将軍パネルで効果・発動状態を確認でき、1戦1回のスキルは戦闘中に「固有スキル発動」で使用します。[全将軍のスキル一覧](GENERAL_SKILLS.md)も参照してください。

徴側・徴弐は**「徴姉妹（徴側・徴弐）」という共同指揮の1枠**。1つの委任先・指揮権・副官状態・通信として扱う。全20枠で、人物としては姉妹を含め21人となる。

ラクシュミー・バーイーの指定に合わせて19世紀までを対象とし、史実の人物と伝説・半伝説の人物を採用する。台詞とイラストはゲーム用の創作。

将軍20枠に2Dイラストを採用。アニメ、海外コミック、セミリアルなデジタルペイント、水彩、ガッシュ、色鉛筆など人物ごとに画風を変えている。日本画・浮世絵・水墨画・3Dは使用しない。徴姉妹は全10表情で2人を一緒に描いた1枠。将軍一覧は通常肖像、戦況通信は準備・進軍・待機・接敵・被攻撃・救援要請・損失・安堵・占領・勝利の表情を表示する。

画像一覧は [assets/generals/catalog.jpg](assets/generals/catalog.jpg)。生成プロンプトと梱包方法は [assets/generals/README.md](assets/generals/README.md) を参照。

「将軍 G」で指揮権を返還すると副官になり、直轄部隊を再委任できる。将軍からの命令・戦況・救援要請が画面に届き、視認した敵将軍の通信も表示する。

## 柵・鷹・デコイ

- **柵（20）**：準備中のみ設置できる木の障害物。ドラッグで連続配置。部隊は通れず、敵は攻撃して破壊する。
- **鷹**：双方1羽ずつ。地形を無視して飛行し、視界を広げる。戦力・攻撃対象には数えない。手動移動と自動巡回に対応。
- **デコイ（30）**：指定した兵種に偽装する囮。近づいた敵には見破られる。準備中のみ設置可能。

## 操作

全部隊の移動に方向別の歩行差分を使用する。歩兵・鉄砲隊・弓隊は脚を交互に動かし、騎兵と象兵も足運びを変える。大砲は砲兵が歩いて押す。実際の進行方向に合わせた8方向表示で、移動距離に応じて4コマを切り替え、止まると待機姿勢へ戻る。[方向・歩行の確認資料](assets/units/README.md) を参照。

左クリック／ドラッグで選択、右クリックで移動／攻撃。Aで攻撃移動、Sで停止、Qで直轄部隊を選択、Dで鷹を選択、Pで鷹の自動巡回、Gで将軍パネル。Spaceで一時停止、＋／－で速度変更、F1またはHでヘルプ。矢印・画面端・中ドラッグで地図移動、ホイールで拡大縮小。タッチ操作も継承する。

## 起動・確認

```powershell
cargo run --release --locked --bin yyikusa-win
cargo test --locked --lib
powershell -ExecutionPolicy Bypass -File tools/build_web.ps1
python -m http.server 8018 --bind 127.0.0.1 --directory dist
```

ブラウザ版は http://127.0.0.1:8018/ を開く。Linux／CIでは `bash build.sh` でもビルドできる。GitHub ActionsでWindows版とブラウザ版を生成する。

Cloudflare設定名は `yyikusa`。公開する場合は `npm run deploy` を実行する。保存先・ブラウザの記憶領域はYYww2とは別名にしている。

## アセット

アプリアイコンとタイトル背景はyyIkusa専用の2Dイラスト。鷹・剣・軍旗の紋章をWindows実行ファイル、favicon、Webアプリ、ホーム画面で共用する。タイトル画面は専用キービジュアル、濃紺・金・朱赤の操作パネル、漂う火の粉で構成する。生成プロンプトと再梱包方法は [assets/branding/README.md](assets/branding/README.md) を参照。

[yyMongolia](https://github.com/ykwyuta/yyMongolia) の本陣建築などを流用。由来と再生成方法は [assets/mongolia/README.md](assets/mongolia/README.md) を参照。8兵種の方向・歩行差分と将軍イラストはyyIkusa専用に生成し、柵・鷹はコードで描画する。武器と砲兵も兵種の原画に含む。
